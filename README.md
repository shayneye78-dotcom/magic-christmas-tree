# 🎄 魔法圣诞树 Magic Tree

用手势种一棵会发光的粒子圣诞树，最后比心召唤毛绒圣诞老人，为你写下 Merry Christmas，并生成一张专属贺卡。

**在线体验：** https://shayneye78-dotcom.github.io/magic-christmas-tree/

## 玩法

1. ☝️ 食指朝上，往左或往右划一下再收回：选树的颜色、灯光颜色
2. 👇 食指朝下停一下：召唤仙女棒
3. 🌀 从下往上螺旋绕圈：种出圣诞树
4. 🤌 五指聚拢变出礼物，🖐 张开放到发光的位置
5. 🫶 双手比心：圣诞老人从树后飞出，接住仙女棒写下 Merry Christmas，然后生成贺卡

没有摄像头也可以用鼠标或触屏体验。摄像头画面只在本机处理，不会上传。

## 背景音乐

点右上角 🎵 可以选一首自己电脑里的音乐作为背景音乐，浏览器会记住。没有选择时播放内置的音乐盒版《Jingle Bells》（公有领域）。

## 技术

单个 HTML 文件：Canvas 粒子 + MediaPipe 手势识别 + three.js 3D 毛绒圣诞老人。字体轨迹使用 Hershey 单线手写体（公有领域）。
